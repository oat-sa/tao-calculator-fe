# REPO CONTEXT

This file contains important context about this repo for [Tonkotsu](https://www.tonkotsu.ai) and helps it work faster and generate better code.

## Setup

```bash
npm install
```

## Build

```bash
npm run build
```

## Development Server

```bash
npm run dev
```

## Lint

```bash
npm run lint
```

## Tests

```bash
npm test
```

## Watch and Build

```bash
npm run build:watch
```

## Watch Tests

```bash
npm run test:watch
```

## Code Coverage

```bash
npm run test:cov
```

## Format Code

```bash
npm run format
```
